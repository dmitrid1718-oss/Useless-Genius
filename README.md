# Useless Genius

Soviet invention archive using AI Net City's base layout. Static HTML, CSS, and JavaScript; no build step.

The opening three entries are catalogue records, not finished articles. Full editorial content is being prepared separately.

Search supports English, Russian, names, subjects, years, and multiple terms. Subject tabs combine with search; card tags reset the subject and search by tag.

To add a card, copy an article in index.html and update its accession number, category, searchable aliases, source links, and visible metadata. Never carry AI Net's data credentials, comments, analytics, or AI news feeds into this project.

## Editorial filing

C supplies full stories; the site owner maintains organization. Eleven subject drawers use memorable labels with explicit subject descriptions. Cards may belong to several subjects (space-separated data-category values). Keep evidence status separate from topic: working device, prototype, proposal, unverified claim. Use abandoned as a lifecycle tag, not an explanation of why a project ended.
